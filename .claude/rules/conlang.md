# Conlang conventions

- Remean grammar and vocabulary live in separate files (`Remean_Grammar.md`, `Remean_Vocabulary.md`). A new word goes into the vocabulary file in the same change that first uses it anywhere else.
- Conlang files are reference documents: tables, bullets and interlinear glosses are fine here, unlike lorebook prose.
- Keep diacritics exactly as written; never normalise them away.
- Any Remean word used in a lorebook should exist in the vocabulary file with the same spelling.
- Svenic keeps Þ and ð, treats y as its own vowel, and has native aspirated onsets (hr-, hl-, hn-). Varngardi writes the same sounds in plain letters and has worn the aspirates down to r, l, n.
- Merhal city names run prefix, fossilised connecting vowel (î, ê or â), suffix. The suffix names the locality; prefixes are deliberately left unglossed, so do not invent etymologies for them.
